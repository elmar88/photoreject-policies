# PhotoReject policies and support

Public privacy, terms and support pages for **PhotoReject: Photo Cleaner**, maintained by [elmar88](https://github.com/elmar88).

- [Privacy policy](https://elmar88.github.io/photoreject-policies/privacy/)
- [Terms of use](https://elmar88.github.io/photoreject-policies/terms/)
- [Support](https://elmar88.github.io/photoreject-policies/support/)
- [PhotoReject](https://elmar88.github.io/photoreject-policies/)

Photo cleanup is free. The optional one-time PhotoReject Pro purchase adds on-device Smart Keeper suggestions and video compression. Smart Keeper checks visible smiles, blinks and photo quality without uploading images or making deletion decisions. Original videos are kept unless the user chooses to delete them after saving a verified compressed copy.

## Updating the pages

Edit the content in `build.py`, run `python3 build.py`, and commit both the generator and the generated `docs/` files. GitHub Pages publishes the `docs/` folder from `main` automatically.

This repository contains public website and policy material. The native iPhone application is maintained separately. App Store release is in preparation.

Support: [support@studioec.nl](mailto:support@studioec.nl).
